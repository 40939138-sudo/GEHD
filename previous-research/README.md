# 歷史研究資料入口

本區是受保護歷史原件與查詢導覽；本輪分類只維護導覽，不改TECHNICAL_HANDOFF.md或technical-data.json。現行命題與方法依[全案主位置](../草稿區/研究與開發計畫/README.md#classification-map-20261017)，任務依該入口指定的Issue／Project；歷史記錄不改寫為現行工具資格。

本區保存兩份歷史衍生資料。現行需求與工作狀態請讀[研究入口](../草稿區/研究與開發計畫/README.md)；本頁於2026-10-17建立、2026-10-19補齊分類導覽，兩份歷史檔的正文與位元組保持原樣。

| 檔案 | 內容與查詢方式 | 使用範圍 |
| --- | --- | --- |
| [TECHNICAL_HANDOFF.md](TECHNICAL_HANDOFF.md) | 2026-10-09 中文技術綜述；先按具名問題查 T 編號，再回來源 | 歷史摘要，並非原始量測；角色／模型優先已由較新的環境貼圖優先取代 |
| [technical-data.json](technical-data.json) | 結構化抽取資料；按記錄 ID、來源路徑及欄位查詢 | 歷史衍生資料，抽取驗證不等於全部語義審查；舊路徑、canonical、授權與狀態不代表本機現況 |

JSON 欄位導覽如下，數量是這份檔案的陣列長度，不能相加當成獨立證據數。

| 欄位 | 分類與數量 |
| --- | --- |
| `schema`、`authority`、`readingBoundary`、`generatedAt` | 格式、衍生資料資格、閱讀邊界與生成時間 |
| `canonical` | 歷史來源身份參照 |
| `humanNeeds`、`method` | 歷史需求及當時整理方法 |
| `coverage` | 抽取覆蓋及枚舉限制 |
| `technicalRecords` | 1,099 筆技術記錄；沿用 `id`、`topics`、`sources`、`sections` 定位，按需核對；`classification=null` 不代填為已驗證 |
| `historicalClaimAudit` | 96 筆歷史主張對帳 |
| `historicalDecisionDisposition` | 12 筆歷史決策處置 |
| `unresolvedSources` | 162 筆來源處理項；各項資格需讀其原因，不能一律稱為遺失 |
| `preservation`、`validation` | 當時的保存與抽取檢查紀錄 |

舊交接內的絕對路徑保留作來源資訊；查本機檔請用本頁連結。需求變更見[需求沿革](../草稿區/研究與開發計畫/01_決策與計畫/整體計畫.md#requirements-history)，來源差異見[閱讀快照異常](../草稿區/研究與開發計畫/03_證據與歷史/來源索引.md#reading-snapshot-drift)。
